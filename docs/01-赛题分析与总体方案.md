# 01 · 赛题分析与总体方案

> 欧莱雅第二届美妆科技黑客松 · 赛道二 **TRUTH GUARDIAN 信任守护师 —— 创造者的 AI 卫士**

## 一、赛题原文拆解

| 维度 | 官方要求 | 我们的理解 |
| --- | --- | --- |
| 定位 | 打造一款"懂美妆内容生态的 AI 鉴真专家" | 不是通用鉴伪模型，必须**懂美妆**：成分、功效宣称、包装、试用图、达人测评 |
| 能力一 | 多模态检测方案，识别被**篡改、拼接或伪造**的文案与图片 | 图像侧 + 文本侧双通道，缺一不可 |
| 能力二 | 构建 Agent，结合**风险预警**与**处理建议** | 不是"打个分就结束"，要能输出**可执行的处置动作** |
| 能力三 | 展示从"识别"到"决策"的**完整闭环** | 演示必须是一条完整流水线：输入 → 证据 → 决策 → 处置 |

**一句话定义产品：**

> **真鉴 TruthGuard** —— 面向美妆电商内容场景的多模态内容鉴真与风控 Agent。输入一张商品图 + 一段推广文案，输出"证据链 + 风险等级 + 处置建议"的闭环决策报告。

## 二、场景与痛点

### 2.1 目标场景（选择理由：贴近欧莱雅真实业务、素材易获取、演示效果好）

1. **UGC / 达人内容审核**：KOL 发布的试用前后对比图、成分宣称笔记
2. **电商商品详情风控**：商品主图被拼接伪造资质、盗用官方图
3. **售后纠纷取证**：消费者投诉"货不对板"，需要判断宣传图是否经过篡改

### 2.2 四类真实痛点

| 痛点 | 典型形态 | 现有手段的不足 |
| --- | --- | --- |
| 效果对比图造假 | 磨皮/换肤/拼贴"使用前后"对比图 | 人工审核主观、无法规模化 |
| AI 生成虚假测评 | 用 AIGC 生成"素人使用照"与编造体验文案 | 肉眼几乎无法分辨 |
| 功效与成分虚假宣传 | "七天美白""医美级""100%有效" | 关键词规则库易被规避 |
| 盗图与资质伪造 | 拼接官方检测报告、伪造专利编号 | 需要像素级取证证据 |

## 三、核心方案：双层证据 + Agent 决策

### 3.1 设计哲学：为什么是"双层证据"

单一技术路线都有明显短板，我们用两类证据互补：

| 层次 | 技术 | 强项 | 短板 | 我们的用法 |
| --- | --- | --- | --- | --- |
| **硬证据**（像素层） | ELA 误差分析、噪声一致性、EXIF/元数据、JPEG 重压缩痕迹 | 客观、可量化、**可可视化**、无需 GPU/API | 不理解语义 | 作为"篡改区域定位"的主证据，输出热力图 |
| **软证据**（语义层） | 多模态大模型（视觉）+ 文本大模型 | 理解"这是否符合美妆常识与合规宣称" | 会幻觉、不可复现 | 作为"语义风险"的补充证据，输出文字理由 |

**关键创新**：硬证据负责"**哪里被改了**"（可解释、可展示），软证据负责"**这句话在说什么、是否越界**"。两者在 Agent 层加权融合 —— 这正是评委最看重的"技术深度 + 可解释性"。

### 3.2 系统三层架构

```
┌────────────────────────────────────────────────────────┐
│ L3 演示层  React：上传 → 流水线动效 → 证据热力图 → 风险报告  │
├────────────────────────────────────────────────────────┤
│ L2 决策层  RiskAgent：证据聚合 → 风险分级 → 处置 → 理由生成  │
├────────────────────────────────────────────────────────┤
│ L1 检测层  ┌──────────────────┐ ┌────────────────────┐ │
│           │ 图像取证引擎       │ │ 文案合规检测引擎      │ │
│           │ ELA/噪声/EXIF     │ │ 违规宣称/虚假测评     │ │
│           │ + 多模态视觉 LLM  │ │ + 文本 LLM          │ │
│           └──────────────────┘ └────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

详见 `docs/02-技术架构.md`。

## 四、四大创新点（路演主推）

### 创新点 1：像素取证 + 语义理解的**双层证据融合**
不只输出一个"伪造概率 87%"的黑箱数字，而是给出"**ELA 在人脸区域异常 + 文案含医疗功效宣称**"这样的复合证据链。评委能看懂、能追问、能信服。

### 创新点 2：美妆垂类**宣称合规知识库**
把《化妆品监督管理条例》《化妆品标签管理办法》《广告法》中可机读的规则沉淀为检测项，例如：

- **绝对化用语**：100% 有效、永久、第一、最
- **医疗功效宣称**：祛痘→治疗、抗炎、医美级、替代激光
- **时限承诺**：七天美白、一夜回春、28 天逆龄
- **伪造背书**：虚构检测机构、未备案的"专利号"
- **成分造假**：宣称含某高价值成分但成分表无对应项

这让系统"懂美妆"，而不是一个通用鉴伪壳子 —— 直接命中赛题关键词。

### 创新点 3：从"识别"到"决策"的**闭环 Agent**
Agent 不是分类器，而是**决策体**：

```
证据聚合 → 风险分级（低/中/高） → 处置动作 → 面向不同角色的建议
```

- 处置动作：`pass 通过` / `review 人工复核` / `flag 警示标记` / `takedown 建议下架`
- 角色化建议：对平台（限流/下架）、对创作者（修改指引）、对消费者（风险提示）

### 创新点 4：**可解释的证据可视化**
ELA 热力图、噪声不一致区域、EXIF 缺失标注，把"算法判断"变成"人能看懂的证据"，直接服务于演示效果与评委信任。

## 五、技术路线对比（为什么不用纯深度学习）

| 方案 | 优势 | 劣势 | 结论 |
| --- | --- | --- | --- |
| 训练端到端伪造检测网络（如 ResNet 系） | 精度高 | 需大规模标注数据、需 GPU、1 个月内难出稳定结果、不可解释 | ❌ 不采用 |
| 纯调用大模型 API 判断 | 快 | 黑箱、无法定位篡改区域、API 抖动 | ⚠️ 作为软证据 |
| **本地取证特征 + 大模型语义 + Agent 决策** | 可解释、可降级、周期短、演示效果强 | 绝对精度不如专用模型 | ✅ **采用** |

**降级策略**：API Key 缺失或超时 → 自动仅用本地取证特征出报告，保证任何环境下演示不断线。

## 六、商业与落地价值（讲给欧莱雅听）

1. **降低合规风险**：自动拦截违规宣称，规避监管处罚
2. **保护品牌信任**：遏制盗图、假测评，维护"创造者—消费者"之间的真实
3. **降本增效**：把人工审核从"全量看"变成"机器初筛 + 人审高危"
4. **可复制性**：取证 + 规则 + Agent 的框架可迁移到香氛、护肤、彩妆各品类

## 八、风险与应对

| 风险 | 应对 |
| --- | --- |
| API 不可用 / 超支 | 本地取证降级模式；设置超时与重试上限 |
| 篡改样本不足 | 自制：Photoshop 拼接 + 在线 AIGC 生成 + 公开数据集 |
| 精度被质疑 | 强调"证据可解释 + 人机协同"，定位为辅助决策而非终审 |
| 队员进度不一致 | 见 `docs/03-Git协作规范.md` 与 `docs/04-赛程计划与任务看板.md` |
| 原创合规 | 仅使用开源算法原理与公开 API，不自研权重，全部代码自有 |
