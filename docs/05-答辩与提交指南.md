## 二、演示 SOP（现场前必做）

### 2.1 启动顺序

```powershell
# 1）后端（新终端）
cd backend
uvicorn app.main:app --port 8000

# 2）前端（新终端）
cd frontend
npm run dev

# 3）确认连通：浏览器打开 http://localhost:5173，右下角应显示"大模型已接入"
```

### 2.2 三个演示样本（提前准备好，别现场找）

| 样本 | 预期结果 | 讲点 |
| --- | --- | --- |
| `samples/fake/fake_01.jpg` + "七天美白，医美级效果，100%有效" | 高风险 / 建议下架 | 命中红线 → 无视分数直接升级 |
| `samples/real/real_01.jpg` + "含烟酰胺与透明质酸钠的保湿精华" | 低风险 / 通过 | 不会误杀合规内容 |
| `samples/gray/gray_01.jpg` + "回购率95%，用了两次就好了，效果无敌，纯天然无添加" | 中风险 / 人工复核 | 分级而非一刀切（实测 31.3 分，非红线违规停留在 review 档） |

### 2.3 断网 / 崩了怎么办（必须演练）

1. **后端挂了**：前端自动展示内置演示样例并提示，仍能讲完闭环 → 快速重启后端即可恢复
2. **没网 / Key 失效**：系统自动进入降级模式，仅用本地取证出报告（界面显示"降级模式"标签）
3. **改崩了**：`git checkout v1.0-demo` 回到演示安全版本
4. **必备份**：提前录一段 3 分钟演示视频，现场放不了就直接播视频

## 四、录屏脚本要点

1. 开场：浏览器全屏打开 `http://localhost:5173`
2. 拖入篡改样本 → 等三阶段流水线走完 → 切到 ELA 热力图，停留 3 秒展示可疑框
3. 逐条念证据："噪声一致性 1.00、医疗功效宣称 0.90…"
4. 拉到风险报告区，点击「下架」按钮，展示"已下发指令"提示
5. 再跑真实样本做对比，最后跑灰色样本收尾

## 五、评委高频追问（背下来）
