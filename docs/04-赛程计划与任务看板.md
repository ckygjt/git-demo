## 五、Q&A 预演（评委大概率会问）

| 问题 | 准备回答要点 |
| --- | --- |
| 检测准确率多少？ | 用自建样本集给出混淆矩阵；强调辅助决策定位 |
| 为什么不训练专用模型？ | 周期内数据/GPU 受限；取证特征可解释性更强，适合风控场景 |
| 大模型幻觉怎么解决？ | 规则库兜底 + 双通道交叉验证 + 证据权重设计 |
| 怎么保证实时性？ | 本地特征毫秒级；LLM 可异步/降级 |
| 商业落地路径？ | 先接内容审核中台，做人机协同初筛，再累积数据训练专用模型 |
| 数据从哪来？ | 自制篡改样本 + 公开数据集 + 公开商品图（注明来源） |
