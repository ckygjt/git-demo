# 测试样本集

> 图片体积大，**不进 Git 仓库**（已被 `.gitignore` 排除）。放在团队网盘，此目录只保留说明与清单。

## 目录约定

```
samples/
├── real/      原始未篡改商品图 + 合规文案
├── fake/      篡改/拼接/AIGC 生成图 + 虚假宣传文案
└── gray/      灰色地带：轻微修图 + 轻微夸大
```

## 命名规范

`{类型}_{序号}.{ext}`，例如 `fake_01.jpg`、`real_01.jpg`
配套文案放在 `samples/texts.csv`：`文件名,文案,预期标签`

## 制作方式

| 类型 | 怎么造 |
| --- | --- |
| 篡改图 | Photoshop/美图秀秀 拼接、换脸、局部磨皮后再存 JPEG |
| AIGC 图 | 通义万相 / Midjourney 生成"素人使用照" |
| 真实图 | 品牌官方公开素材、自己拍摄（注意版权，注明来源） |
| 虚假文案 | 参考电商常见夸大话术自行撰写 |

## 目标规模

30 组（真 10 / 假 15 / 灰 5），用于路演时给出准确率数据。
